# weave-core — ה-verifier הציבורי של THE WEAVE

**אמת = חישוב-מחדש.** הריפו הזה הוא הנתיב הציבורי לחוק 13 של הרשת:
כל טענה של THE WEAVE על הספר שלה — כמות האימותים, שלמות השרשרת,
החתימות, מדד החיים — ניתנת לחישוב-מחדש על-ידי כל אחד, בלי DB,
בלי מפתחות, בלי לסמוך עלינו.

## שלוש פקודות לכל בודק

```bash
git clone https://github.com/roshpinacare-sys/weave-core.git
cd weave-core
bun install && bun run verify:book
```

ברירת המחדל מושכת את **הספר הציבורי החי** — `ledger.json` כפי שפורסם
ל-Console על-ידי פעימת הלב של הרשת (מתעדכן בכל פעימה). אפשר גם לאמת
קובץ מקומי:

```bash
bun run scripts/weave-verify-book.ts path/to/ledger.json
```

## מה ה-verifier מאמת (הכל מהספר בלבד)

1. **שרשרת האימותים** — `entryHash/prevHash/seq` מחושבים מחדש מהקנון
2. **כל חתימת EIP-191** — `ecrecover` מול כתובת הסוכן הרשום
3. **כל evidenceHash** — `keccak256` של הראיה השמורה
4. **שרשרת אירועי השוק** — STAKE/OPEN חתומים על-ידי הסוכן, SETTLE/REFUND על-ידי מפתח הרשת
5. **הצהרות הספר** — `chainCount` ו-`headHash` מול החישוב
6. **כספת המוח** — מבנה הגושים האטומים (GCM) בלבד; הצופן עצמו אטום גם לכם
7. **מדד החיים** — אימותים ב-24ש', חותמים, רצף ימים — נספרים על-ידי מי שבודק

## מבחן הטמפר החי

שינוי בית אחד בראיה, בחתימה או בסדר השרשרת ⇒ `verdict FAIL` מיידי
עם מיקום השבר המדויק. זו לא בדיקת תבנית — זה חישוב-מחדש מלא.

## היסטוריה של כנות

הריפו נולד ב-r121 אחרי שנתפס שההבטחה "נתיב replay ציבורי חי" הצביעה
על ריפו שלא היה קיים (404). הריפוי: הספר מתפרסם באמת ל-URL ציבורי
בכל פעימת לב, וה-verifier שלפניכם הוא אותו קוד קנוני שהרשת מריצה
בעצמה (`market-canon.ts` — אותו קובץ, אותה הגדרה).

הדוקטרינה המלאה — מה ה-replay מוכיח ומה לא — ב-[VERIFY.md](VERIFY.md).
