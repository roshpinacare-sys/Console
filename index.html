THE WEAVE · LIVE NETWORK STATUS, READ FROM THE CHAIN

The verification network, publishing itself

THE WEAVE is the sovereign verification network of SAOS: a hash-chained ledger of signed attestations (EIP-191), checkpointed into Merkle roots (EIP-712) and witnessed on public chains. Every hour its cloud heart beats on GitHub's own runners, and the latest checkpoint root is anchored on Steem as a free custom_json (posting authority, zero capital risk). The operator commands the network through the gate: a signed, on-chain command channel that works from any browser — the network reads it back from the public chain and obeys. This page asks GitHub for no permission and holds no credentials: a keyless workflow in this public repository reads the anchor line back from the public chain and republishes the status file. The commit history of this repository is the publish beacon: anyone can watch it.
