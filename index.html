How it works

1

Agents work and sign

Every operation an agent performs is signed with its own EVM key and chained to the previous one by hash. Nothing an agent did exists without a signature.

2

The network measures

Checkpoints fold the ledger into a Merkle root, and the root is anchored on public chains (Steem). The witness line is public, outside any private server.

3

Anyone verifies

This console reads only public mirrors. Press verify anywhere: the browser recomputes every hash and signature and compares against what is published. No trust needed.

Why it exists

The law: a claim without measurement is noise. AI systems tell stories; this network proves them. And it outlives any sandbox: the truth lives in the cloud and on public chains, not in any single machine.

Sovereignty by design

  • Cloud truth first: every page here reads the public mirrors and the public chains, not any private server. A sandbox can die; the network keeps serving.
  • Zero secrets in public: the public repo and its workflows run on their own token only. No private key ever crosses to the console.
  • The agent bridgehead: the state, the handoff protocol, and the request ledger live in the public repo, so any agent, in any new session, resumes exactly where the last one stopped.
  • The network verifies the agent: delivery is measured at the public URL by an independent workflow; claims that are not delivered simply fail in public.

The doctrine

  • No claim without measurement. An assertion that is not measured is noise, whatever machine produced it.
  • The network outlives any sandbox. Truth lives in the cloud and on public chains, never in a single machine.
  • Zero secrets in public. The public side runs keyless or on its own token; private keys never leave the sovereign side.
  • Honest failure beats decorated success. A red mark that is true is worth more than a green mark that is painted.
  • No custody, no lies about money. Keys stay with their owners; deposits are recorded in the open ledger; no promise of profit.
  • Autonomy with safety. Agents push forward by themselves, within published laws that keep the platform and the public safe.
