ארבע דלתות לאותה ריבונות

Identity API (חי היום)

קריאה אחת מוכיחה שחשבון Steem/Hive‏ וכתובת EVM‏ חולקים מפתח אחד. ההוכחה נקראת מהשרשרת (saos.id.v1‏ -> EIP-191‏ -> התאמת סמכות חיה). מדידה במונים, ספר-מכסות, תוצאות FAILED הגונות. SDK‏ ללא תלויות: saos-id-verify.

בורסה ריבונית + כלכלה

ספר-זמנות בנאמנות מלאה, אצוות CoW עמידות-מבנית להתקפות סנדוויץ', ve(3,3) קנה-ושרוף (40% כל 600 בלוקים, תחום ברווח נמדד), DCA‏ ו-TP/SL בלי שומרים, לאנצ'פד עם השלמה חיה (100% POL‏). ‏383,836 סירובים מפורסמים.

נוטריון JUMPPER

נוטריון הוכחות באצוות: 10K טענות בשורש אחד, ‏$0.0000081 לרשומה. מסילה חינמית חיה עם קבלה אמיתית (בלוק Steem‏ 109,496,567‏). עוגני-תיקון מפרסמים תיקונים במקום שבו השגיאה חיה. epochguard מונע פיצולי-שרשרת במקום רק לדווח עליהם.

ארנק + מנועי הוכחה

משמורת-עצמית על 7 רשתות (M0-M4 מאומת), המפתחות לא עוזבים את הלקוח. שעון אטומי: 6 רשתות לשורש אחד של 32 בייט, בלי מפתחות, ‏$0, ‏15.9ms. THE-TOWER: סייר ה-Ethereum‏ שלנו שמציג את העוגנים שלנו.
