Operating rules (non-negotiable)

  1. Never post two near-identical texts. The doctrine's founding incident was five near-duplicate posts. Across accounts, rotate topics; across networks, rewrite the angle, the opener, and the examples. Same subject, different post.
  2. One post per account per day is plenty. The rails allow four. Quality is the ranking function on all three chains, and the payout window is seven days: the algorithm and the whales both reward consistency over bursts.
  3. First paragraph carries the post. On every frontend it becomes the preview. Topic plus value in two sentences, no throat-clearing.
  4. Titles: keyword early, curiosity honest. A misleading title burns reputation that seven-day payouts can never repay.
  5. Update by edit, never by repost. The edit primitive exists; the chains record edits; readers respect them.
  6. Every number in a post must be true and public. Chain data, published research, or your own measured receipts. If you cannot point at it, cut it.
  7. Comments before posts. Five thoughtful comments earn more trust (and on Blurt, more curator weight) than a fourth post nobody reads.
  8. Zero dashes, zero emoji, zero banned words. Run new drafts against style-human.md before submitting to the exposure gate.

Extending the kit

Write new posts only after reading style-human.md. Then self-check: does it name a specific number? does it end on a point instead of a summary? does any sentence start with a banned opener from the style-human list? If yes to the last one, rewrite. Submit through the normal pipeline; the exposure gate gets the final word, as it should.
