  • השלילה אומתה מדיד: GET /user עם הטוקן-המותקן -> HTTP 401 · git ls-remote -> "Invalid username or token" · דחיפות/שידורים/מטריצה - הכל fail-closed כרגע.
  • טוקן חדש לא נחת: הקובץ Roshcaregt (2).txt שהועלה זהה ביט-ביט לטוקן-הישן (fingerprint sha256:222832039d20) - העלאה-כפולה של הישן, לא PAT חדש.
  • שום נזק לא נגרם: שלוש החנויות המקומיות תקינות ומסונכרנות (canonical=legacy; broker=אותו-ערך עם שורה-חדשה של-ה-broker) - הן פשוט מחזיקות טוקן-מת.

ראיות (מדידות)

  • gh-rotate.sh (אחרי-שיפור חסין-שמות) רץ fail-closed: סריקת כל upload/*.txt - Roshcaregt(2)/Roshcaregt -> זהים-למותקן (דילוג) · saos-admin-key -> 401 (סוד-אחר, תקין שנדחה) · קונמי/ראשגד -> 401 · exit=1 · אפס שינוי בחנויות (fingerprints הוכחו לאחר-הריצה).
  • git push מקומי בלבד: הקומיט-המקומי של שיפור-הסקריפט + פסק-זה מוחזקים בריפו המקומי, ממתינים לדחיפה.
  • הפלטפורמה עצמה חיה ובריאה: :3000 -> 200 · /api/saos/status -> ok עם מטריצת-רשתות חיה (v89).

(מומלץ fine-grained: resource-owner roshpinacare-sys, כל הריפואים השותפים + saos-sovereign-platform, Contents: Read+Write; חלופה: classic עם repo, workflow).

  1. העלה אותו למכונה כקובץ .txt כלשהו לתיקיית-ההעלאות (השם לא משנה יותר - הסקריפט מוצא לבד) · לא בצ'אט.
